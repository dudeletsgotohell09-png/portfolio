MoodFlick: Mood-based Film Recommendation System

A mood-based film recommendation system built with C# WPF (.NET 8.0) and MySQL. It gives personalized movie suggestions using weighted scoring of mood, genre, language and era, with a database-driven catalog, secure login with role-based access, and a companion web interface.

Automated Smart Parking System

An automated parking system for university faculty and staff. A Raspberry Pi 4 with a camera module watches the entry gate, detects and reads number plates with a fine-tuned YOLO11n model and EasyOCR, then checks the plate against a whitelist database before opening a servo-controlled barrier and assigning a parking slot by faculty zone. A live web dashboard tracks slot occupancy, entry logs, and system health, deployed publicly via a Cloudflare Tunnel on a custom domain.

Raspberry Pi 4 SQLite Cloudflare Tunnel YOLOv11n
Code

Fresh: Online Grocery Store Management System

Fresh is a full-stack online grocery store I built using only HTML, CSS, JavaScript, PHP and MySQL. Customers can browse and search the catalogue, manage a cart, redeem promo codes and track orders. Administrators oversee inventory, order fulfilment and customer enquiries through a dedicated dashboard. The platform features role-based security, a responsive interface and a dark mode.
